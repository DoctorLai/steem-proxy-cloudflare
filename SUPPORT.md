# Support

## Before Opening an Issue

1. Read the setup and deployment notes in [README.md](README.md).
2. Reproduce the problem against the latest `main` branch.
3. Run `npm run check` locally.
4. Check existing [issues](https://github.com/DoctorLai/steem-proxy-cloudflare/issues).

For reproducible bugs, open a
[bug report](https://github.com/DoctorLai/steem-proxy-cloudflare/issues/new/choose) with the request
method, sanitized payload, status code, response body, relevant response headers, and Worker
version. Never post credentials or private RPC data.

Feature proposals are welcome through the feature request template. General support and public
instance availability are provided on a best-effort basis without an uptime guarantee.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
